# College Feedback & Sentiment Analysis Platform

An intelligent AI-powered student feedback collection and sentiment analysis platform built for academic institutions.

## Features

- **Feedback Submission**: Intuitive multi-category feedback forms (Faculty, Curriculum, Infrastructure, Labs, Library, Canteen, Placement, Administration).
- **Sentiment & Emotion Analysis**: Automatic classification of feedback sentiment (Positive, Neutral, Negative) with polarity scores and keyword extraction.
- **Interactive Analytics Dashboard**: Real-time visual metrics, department comparisons, sentiment distribution charts, trendlines, and exportable reports.
- **Role-Based Authentication**: Secure student, faculty, and administrator workflows with Base44 entity integration.
- **Terminal & Activity Monitor**: Live log stream of incoming feedback and sentiment processing.
- **Modern UI Suite**: 40+ Shadcn/ui responsive components with Tailwind CSS styling.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Tech Stack
- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS & Lucide Icons
- **Components**: Radix UI / Shadcn UI
- **Charts**: Recharts
- **Data State**: TanStack React Query
- **Routing**: React Router DOM v6
- **Backend / Data**: Base44 Client & LocalStorage Sync
